# Real-device checklist

The automated suite uses desktop Chromium with throttling and emulation. It cannot tell you how the song book feels on a real phone in a dark, loud venue. Please run this short list once on an iPhone (Safari) and once on an Android phone (Chrome), on the live link, with the screen brightness set low like it would be on the night.

For each line: do the action, compare with "Expected". Note the phone model, the OS version and anything that differs.

| # | Check | How | Expected |
|---|---|---|---|
| 1 | Load time on mobile data | Wi-Fi off, open the link in a new private tab on mobile data (4G or better). Type `love` as soon as the box is there. | The page and the box appear within about 2 seconds. Typing is never blocked. On the very first visit the song data downloads once (about 1 MB): on 4G the first results appear within about 2 seconds after the page has finished loading; on a slow connection (slow 3G) the first visit can take 6 to 10 seconds, and "Loading song book…" shows meanwhile. That wait is the one-time data download. Open the link again in the same tab: results are quick. Note the time you saw and the kind of connection. |
| 2 | Typing with the on-screen keyboard | Tap the box, type `hotel californa` (with the typo). | The search keyboard opens with a Search key, no capital letter at the start, no autocorrect. The right song number is among the first rows. Each letter updates the list without lag. |
| 3 | One-handed reach: clear | Hold the phone in one hand, type something, reach the X with your thumb. | The X is reachable and a tap clears the text and keeps the keyboard open. |
| 4 | One-handed reach: back chevron | Search `eagl`, tap an artist, reach the back chevron at the top left with your thumb. | The chevron is reachable (a stretch on a large phone is expected, nothing else on the screen needs the top corners) and a tap returns to the same results, at the same scroll position. |
| 5 | Back, forward and swipe-back | Search, open an artist, then use the phone's Back button (Android) or swipe from the left edge (iPhone). Then go forward. | Back returns to the results of the search, scrolled to where you were, with the cursor back in the search box. It does not leave the site. Forward returns to the artist. A swipe-back from the first screen leaves the site (typing does not add history entries). |
| 6 | Enlarged system text | iPhone: Settings, Accessibility, Display and Text Size, Larger Text, turn on Larger Accessibility Sizes and drag the slider to the largest. Android: Settings, Display, Font size and display size, Font size, largest. Reload the page and search `love`. | The song number is never drawn over the title. Rows get taller instead of cutting text. No sideways scrolling. Note: iOS Safari only follows the system text size if the page asks for it; if nothing changes on iPhone, use Safari's page zoom instead (the aA menu in the address bar, 200%) and check the same things. |
| 7 | VoiceOver / TalkBack: rows | Turn on VoiceOver (iPhone) or TalkBack (Android), search `love`, swipe through the results. | Each row is read as one sentence that starts with the song number: "Song 123, Title by Artist". The number is not read twice. After the search settles, one phrase giving the TOTAL number of matches is read, such as "1,234 songs found" (not "50": only the first 50 are shown, the count is for all matches), and not one phrase per letter. |
| 8 | VoiceOver / TalkBack: opening an artist | With the screen reader on, search `eagl`, double-tap an artist. | The artist is read as "Name, N songs" before you open it. After opening, focus is on the heading and it reads "Name, N songs" once (if it is read twice, tell us: it is a known thing we could not test without a real screen reader). The back button is read as "Back to results". Going back puts focus in the search box. |
| 9 | The clear X in Safari | In iPhone Safari, type a few letters. | One X only, on the right of the box. Not two. |
| 10 | Offline or airplane mode | Open the site, then turn on airplane mode and reload, or open it in airplane mode from the start. | If the page itself cannot load, the browser's own offline page shows (the site is not an offline app). If the page is open and the data has not loaded, typing shows "Couldn't load the song book. Check your connection and try again." with a Try again button. Turning the connection back on and tapping Try again loads the data and shows the results for the text you typed. |
| 11 | Rotation | Rotate to landscape and back with results open, and with an artist open. | The layout stays one column, nothing is cut off, the search box stays at the top, the scroll position is kept. |
| 12 | Dark venue conditions | Brightness low, in a dim room. Look at both the dark theme (default) and, with the sun/moon button, the light theme. | Song numbers, titles and the artist lines are readable at a glance. The box outline is visible. Tapping the sun/moon button switches the theme; reloading goes back to dark (the choice is not saved). |
| 13 | Home-screen icon, label and link preview | Add the site to the home screen (Share, Add to Home Screen). Look at the icon and the name under it. Then paste the link into WhatsApp or Messenger. | The icon is the amber double music note (two notes joined by a bar) on a dark square. The label on the home screen is "SongHub" on iPhone. Android uses the page title ("SongHub Songbook: find your karaoke song number") and may shorten it. The link preview shows the SongHub Songbook card. The icon and the card are awaiting your approval (see DECISIONS A-013). |
| 14 | Wi-Fi dropping mid-load | Wi-Fi on, open the link in a new private tab and type `love`. While "Loading song book…" is showing, turn Wi-Fi off (switch mobile data off too). | After a moment the box shows "Couldn't load the song book. Check your connection and try again." with a Try again button, and your text is still in the box. Turn the connection back on and tap Try again: the results for your text appear. |
| 15 | Opened from a home-screen shortcut | Tap the icon you added in step 13. | It just opens the page in the browser, like opening the link. Nothing is stored for offline use: with no connection the browser's own offline page shows (this site is not an offline app). |
| 16 | Data Saver mode (Android) | Chrome, Settings, Lite mode / Data Saver on (or the phone's own data saver). Open the link and search `hotel californa`. | The page loads and the right song is among the first rows. If the browser or the phone blocks or delays the song data, the retry message shows and Try again works. Note what you saw. |
| 17 | Largest artist list on a low-memory phone | Close other apps first. Search `unknown`, open the artist "Unknown" (the largest list: 568 songs). Scroll to the bottom, then tap Back. | The list opens within a second, scrolling is smooth, the phone does not freeze and the page does not reload by itself. Back returns to the results. Note the phone model, and tell us if you can find a longer list than 568 songs. |

When something does not match, send the line number, the phone and what you saw (a screenshot helps). Please do not send raw song titles from the list in screenshots to people outside the team if that matters to you: the book contains strong language.
